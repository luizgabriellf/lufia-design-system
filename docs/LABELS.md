# Labels

Labels are defined in [`.github/labels.yml`](../.github/labels.yml). Prefixes group them:

- `type:` what kind of change it is (`bug`, `feature`, `rfc`, `docs`, `chore`).
- `area:` where it lives (`a11y`, `tokens`, `components`, `storybook`, `build`).
- `status:` where it is in triage (`needs-triage`, `blocked`, `help wanted`).
- `breaking change` marks anything that needs a major version and a migration note.
