## Quick start

Until the package is on npm, install a tagged release straight from GitHub. The tag builds itself on install, and React 19
and React DOM 19 are the peer dependencies.

```bash
npm install github:luizgabriellf/lufia-design-system#<latest-tag>
```

Import the tokens and **one** theme once, at the root of your app, then pick components from the package root or from a
per-component entry point.

```tsx
// app/layout.tsx
import "@lufia/design-system/tokens.css";
import "@lufia/design-system/themes/default.css";
```

```tsx
import { EmptyState } from "@lufia/design-system/components/EmptyState";

<EmptyState title="No documents yet" body="Documents you upload will appear here." />;
```

Components ship CSS Modules, so your bundler (Next.js, Vite) processes them. Strings in the snippet are plain literals: in
your app every user-facing string is a prop, and the package has no translation layer.

## Theming

Light and dark follow `prefers-color-scheme`. Force one, or choose a named theme, with attributes on `<html>`. The
same markup below is rendered under each combination.

the `--lufia-*` tokens (see **Foundations / Creating a theme**).
