# Typography

Each app loads its own fonts with `next/font` and exposes them as `--font-space-grotesk`, `--font-ibm-plex-sans` and
`--font-ibm-plex-mono`. The family tokens read those variables and fall back to named system stacks, so Storybook and
unconfigured apps still render legibly.

## Line height

<TokenTable group="font.line-height" />

Body copy uses `normal` (1.5) or `relaxed` (1.6); headings use `tight`. Text must stay readable at 200% zoom and reflow
at 320px without horizontal scrolling (WCAG 1.4.4 and 1.4.10), so prefer `rem` over `px` for type.
