# Radius and borders

Corners step up with the size of the surface: small for chips and badges, `control` for inputs and buttons, `card` and
`panel` for containers, `full` for pills and avatars.

## Border width

The thick width (2px) is used for focus rings. Focus indicators are never removed; a Stylelint rule forbids
`outline: none` without a replacement.
