# Colors

Colours are defined in three layers (see ADR 0001):

1. **Primitive** (`core.color.*`): the raw palette. Components never read these.
2. **Semantic** (`color.bg.*`, `color.text.*`, `color.border.*`, `color.accent.*`, `color.status.*`, `color.focus.*`):
   what components read, as `--lufia-color-*` custom properties.
3. **Component**: only where a component needs its own override.

Each theme ships a light and a dark set, plus a `forced-colors` mapping to system colours.

## Contrast

CI fails when any listed pair drops below WCAG 2.2 AA: **4.5:1** for text, **3:1** for non-text UI such as the focus
ring. Translucent tokens are composited over the canvas before measuring. Borders are decorative separators and are not
in this list; do not rely on them alone to identify a control.
