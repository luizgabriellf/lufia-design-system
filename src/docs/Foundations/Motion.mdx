Motion keeps people oriented: where something came from, where it went, what just changed. If it does not do that, leave
it out. Everything on this page is a token, and every token respects `prefers-reduced-motion` by itself.

The full rules live in [`docs/MOTION.md`](https://github.com/luizgabriellf/lufia-design-system/blob/main/docs/MOTION.md).
The primitives (Reveal, Collapse, Skeleton, AnimatedNumber, ChangeHighlight, `usePrefersReducedMotion`) are under
**Motion** in the sidebar, and the `lufia-verify-motion` command checks your own source against these rules.

## Durations

Exits are always shorter than entrances. Nothing in application UI should exceed 300 ms; `medium` and `slow` are for
marketing-style reveals and large surfaces.

## Reduced motion

Under `prefers-reduced-motion: reduce`, `tokens.css` collapses every `--lufia-motion-duration-*` to `0.01ms` and every
`--lufia-motion-distance-*` to `0rem`. Durations stay just above zero, not zero, on purpose: `transitionend` and
`animationend` still fire, so code that waits for them keeps working, and the end state is reached on the next frame.

- Anything built from the tokens needs no extra work.
- Endless loops (spinners, shimmer) are **stopped**, not shortened: a 0.01 ms loop is a strobe. Add a
  `@media (prefers-reduced-motion: reduce)` rule for them.
- JavaScript-driven motion reads `usePrefersReducedMotion()` and renders the final state.
- Reduced motion means _less_ motion, not less information.

## Rules in short

1. Animate `transform`, `opacity` and similar compositor properties. Never `width`, `height`, `top`, `left` or margins.
   [Collapse](?path=/docs/components-motion-collapse--docs) is the approved way to animate height.
2. Durations and easings come from tokens, never literals.
3. Only real state changes animate, never first paint or every re-render.
4. Motion never carries meaning alone and never blocks input.

## Using the tokens

```css
.panel {
  transition:
    transform var(--lufia-motion-duration-enter) var(--lufia-motion-easing-out),
    opacity var(--lufia-motion-duration-enter) var(--lufia-motion-easing-out);
}
.panel[data-closed] {
  opacity: 0;
  transform: translateY(var(--lufia-motion-distance-rise));
}
```
