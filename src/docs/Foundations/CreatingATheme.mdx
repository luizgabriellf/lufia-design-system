A theme is a set of values for the semantic `--lufia-color-*` custom properties. Components read only those, so an app can
brand the whole system without touching a component.

## In your app (recommended)

Define the properties in your own stylesheet, scoped to a name of your choosing:

```css
[data-lufia-theme="acme"] {
  color-scheme: light;
  --lufia-color-bg-canvas: #fafafa;
  --lufia-color-text-default: #111111;
  --lufia-color-accent-default: #0a5cff;
  --lufia-color-text-on-accent: #ffffff;
  /* ...every token in the list below */
  --lufia-font-family-body: var(--my-body-font), system-ui, sans-serif;
}

[data-lufia-theme="acme"][data-lufia-mode="dark"] {
  color-scheme: dark;
  /* dark values */
}

@media (prefers-color-scheme: dark) {
  [data-lufia-theme="acme"]:not([data-lufia-mode]) {
    color-scheme: dark;
    /* dark values again */
  }
}
```

Then set `data-lufia-theme="acme"` on `<html>`. Typography tokens (`--lufia-font-family-*`) and any other shared token can be
overridden the same way.

## In this repository

To add a theme to the package itself, copy `tokens/themes/example-brand.light.tokens.json` and `.dark.tokens.json`, rename
them, and add the name to `THEMES` in `scripts/build-tokens.mjs`. Values are DTCG tokens that alias into the palette in
`tokens/primitive/color.tokens.json`. `npm run contrast` then checks every text and UI pair against WCAG 2.2 AA.

## Tokens to define

Every theme must define: `bg.canvas`, `bg.surface`, `bg.surface-raised`, `bg.surface-solid`, `bg.field`, `text.default`,
`text.muted`, `text.subtle`, `text.on-accent`, `text.accent`, `border.subtle`, `border.strong`, `accent.default`,
`accent.hover`, `accent.subtle`, `accent.border`, `focus.ring`, and the `status.{success,warning,danger,ai}` groups
(`fg`, `bg`, `border`), `status.danger.solid`, `status.danger.on-solid` and `status.neutral.{fg,bg}`.

Optional: `bg.field-autofill`, the fill behind text the browser autofilled. It defaults to `bg.field`; define it when your
field colour is translucent or the autofilled state needs its own tint.

Optional: `skeleton.bg` and `skeleton.shine` (`--lufia-skeleton-bg`, `--lufia-skeleton-shine`), the fill of a loading
placeholder and the band that sweeps across it. Without them a skeleton uses `border.subtle` and a 60% mix of
`bg.surface-solid`. Keep the shine lighter than the fill in both modes. Skeletons are decorative, so no contrast minimum
applies.

Recommended for a dark mode: `shadow.sm`, `shadow.md` and `shadow.lg` (`--lufia-shadow-*`). The shared values are tuned
for light canvases, where a soft black shadow is enough; on a dark canvas it disappears and floating surfaces (the phone
floating bar and sheet, modals, menus, the command palette, toasts) lose their lift. The package's dark modes use a
stronger shadow and, on `md` and `lg`, a 1px inset top highlight, the edge that catches the light. Copy them from
`tokens/themes/default.dark.tokens.json` or set your own.

## Checklist

- Text on every surface: 4.5:1 or better. Focus ring and accent against canvas: 3:1 or better.
- Provide both light and dark, or document that one is unsupported.
- Under `forced-colors: active` the package maps tokens to system colours for you; do not fight it.
