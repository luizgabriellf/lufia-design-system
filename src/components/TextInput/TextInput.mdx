<Section id="overview">

A single-line text control: a native `<input>` in a bordered box, with optional prefix and suffix slots for units, signs and
icons.

<Canvas of={Stories.Default} />

### Usage

```tsx
import { FormField } from "@lufia/design-system/components/FormField";
import { TextInput } from "@lufia/design-system/components/TextInput";

<FormField label="Amount" hint="Without tax." error={errors.amount}>
  <TextInput name="amount" prefix="EUR" inputMode="decimal" />
</FormField>;
```

Strings in the snippet are plain literals. In your app they arrive through props from whatever copy or i18n layer you use.
Rest props, `type` and `ref` go to the native input; `className` goes to the box.

- **Disabled** controls are removed from the tab order and the submission. Use them sparingly, and say why in the hint.
- **Read-only** controls stay focusable, selectable and submitted, and have a dashed border. Use them for values the person
  can see and copy but not change.
- **Invalid** adds a second line inside the border and, through `FormField`, the error message with an icon.

### Prefix and suffix

<Canvas of={Stories.PrefixAndSuffix} />

Slots hold short text or an icon. A prefix or suffix that carries meaning ("EUR", "kg") is text in the accessibility tree, so
it is read with the control's description; mark a purely decorative icon `aria-hidden`. A suffix may contain a button, which
is then its own tab stop.

### Compact

<Canvas of={Stories.CompactBesideSelect} />

`size="sm"` is the compact control for toolbars and filter rows. It has the metrics of `Select size="sm"` (a 2 rem box, the
small font size, tighter padding), so the two line up in one row, and it still fills the width it is given. Give it an
`aria-label` or a visually hidden label, as there is little room for a visible one. On touch screens and below 40 rem it grows
to the 44 px touch target, as `Button` and the compact `Select` do; the default size is unchanged.

<Section id="accessibility">

### Accessibility

| Key / action | Behaviour                                                              |
| ------------ | ---------------------------------------------------------------------- |
| Tab          | Moves focus into and out of the input (and to a button in the suffix). |
| Typing       | Native text entry. Nothing is intercepted.                             |

- Always inside a `FormField`, or give `aria-label`. A placeholder is not a label.
- The box draws a 2px focus ring around the whole control; the native outline is replaced, not removed. Under `forced-colors`
  the ring uses `Highlight`, and an invalid control gets a thicker border.
- Height is at least 44px; the text is 16px so iOS does not zoom on focus. The compact `size="sm"` is 32px with 14px text on a fine pointer and grows to 44px on touch screens and phone widths (never below the 24px minimum of WCAG 2.5.8).

</Section>

<Section id="guidelines">

### Do and don't

<TextInputDoDont />

### When to use

- Short free text, numbers, e-mail, URLs, passwords: anything that fits on one line.
- Set `type`, `inputMode` and `autoComplete` for the data: they pick the on-screen keyboard and enable autofill.

### When not to use

- More than one line of text: use `Textarea`.
- A choice from a known list: use `Select` or `Combobox`.
- Searching: use `SearchInput`, which adds a clear button and debouncing.

### Content guidelines

Placeholders show an example ("Quarterly report"), never an instruction and never the label again. Units go in the prefix or
suffix, not in the label. Keep error text next to the field, in the `FormField`.
