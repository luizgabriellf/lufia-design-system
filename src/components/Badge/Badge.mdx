<Section id="overview">

A short, non-interactive label for a category, a count or the state of a record. `StatusBadge` is the same component with a
dot on by default.

<Canvas of={Stories.AllTonesWithDot} />

### Usage

```tsx
import { Badge, StatusBadge } from "@lufia/design-system/components/Badge";

<Badge tone="info">In review</Badge>
<StatusBadge tone="danger">Overdue</StatusBadge>
```

Strings in the snippet are plain literals. In your app they arrive through props from your copy layer.

### Tones

| Tone      | Meaning                                             |
| --------- | --------------------------------------------------- |
| `neutral` | A plain label, or a state with no judgement (draft) |
| `info`    | Something in progress or worth knowing              |
| `success` | Done, approved, healthy                             |
| `warning` | Needs attention soon                                |
| `danger`  | Failed, overdue, blocked                            |
| `ai`      | Content produced or suggested by an assistant       |

The `ai` tone exists so generated content is always marked as such; pair it with text that says so.

A badge wraps by default. Where a tall pill would not work (a table row, a card header), set `truncate`: one line and an
ellipsis, the full text as the native tooltip and in the DOM. In an auto-layout table the column grows with its content, so
cap the badge with `--lufia-badge-max-inline-size`. A badge never paints past its pill or its parent.

### Corner radius

Badges are pills. A theme can change the corner with the `--lufia-badge-radius` component token (default `--lufia-radius-full`). See [Theming components](?path=/docs/foundations-theming-components--docs).

### Keyboard

A badge is not interactive and takes no focus. If it needs to act, use a `Button` or `Link`.

### Accessibility

- The text is always present and carries the meaning. The tone and the dot only reinforce it (WCAG 1.4.1), so never omit
  the text and never reuse one word for two tones.
- The dot is decorative and hidden from assistive technology.
- Every tone's text meets 4.5:1 on its own background in light and dark; the contrast check enforces the status pairs.
- In forced-colors mode the border and dot use system colours, so the shape remains.

</Section>

<Section id="guidelines">

### Do and don't

<BadgeDoDont />

### When to use

- A status in a table row, a card header or a detail page.
- A count or category next to a heading.

### When not to use

- A message that needs to be read now: use a toast or an alert.
- Anything clickable.
- Long sentences. Past two or three words, write text instead.

### Content guidelines

One to three words, sentence case ("In review", not "IN REVIEW"). Say the state, not the colour. Long text wraps instead of
truncating.
