<Section id="overview">

Horizontal bars with the name and the value as text above each track. One scale per list: the largest row fills the track.

<Canvas of={Stories.WithTotal} />

### Usage

```tsx
import { BarList } from "@lufia/design-system/components/BarList";

<BarList
  title="Items by region"
  summary="North has the most items."
  rows={[
    { key: "north", name: "North", note: "12 sites", value: "1,240", amount: 1240 },
    { key: "south", name: "South", value: "860", amount: 860, tone: "warning" },
  ]}
  total={{ label: "Total", value: "2,100" }}
/>;
```

Add `reference` for a shared target and `titleVisibility="hidden"` when a heading of your own already names the list. Both are off by default.

```tsx
<BarList
  title="Items by region"
  titleVisibility="hidden"
  reference={{ amount: 800, label: "Target: 800 per region" }}
  rows={rows}
/>
```

`value` stays on one line by default, which suits numbers. For a value that is text ("12 of 40 sites checked"), set `valueWrap`: it wraps and breaks inside long words, takes at most half the row, and the name keeps the rest. A longer remark still belongs in `detail`, which always wraps.

Strings in the snippet are plain literals. In your app they arrive through props from whatever copy or i18n layer you use; the package has none.

### Accessibility

- The text is the data. It is a `figure` named by its `title`, and every name and value is a list item a screen reader reads in order. The bars are `aria-hidden` shape on top, so no separate table is needed.
- Format `value` yourself (it is what people read); the bar is drawn from `amount`.
- `reference` draws a dashed tick on every track, on the same scale as the bars (it counts towards the scale). The tick is shape only: its `label` is printed as a legend under the list and is the figure's accessible description, so write what it means and its value ("Target: 800").
- `titleVisibility="hidden"` keeps the `title` as the figure's accessible name for screen readers only.
- A written `summary` says what the bars show.
- The draw-in is `transform` only and plays once, on mount; it is removed under `prefers-reduced-motion`.
- In `forced-colors` mode tracks get a border and fills use `CanvasText`.

</Section>

<Section id="guidelines">

### When to use

- Comparing a handful of categories by one measure.
- A breakdown that fits a card.

### When not to use

- More than about ten rows: use a table.
- Two measures per row: use a table, or two lists.
- Time series: use `Sparkline`.
- Nothing to show: it renders nothing, so use an `EmptyState`.
