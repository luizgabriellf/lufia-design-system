<Section id="overview">

A full-width row that is one button: a leading slot, a title, an optional description, a trailing slot and a selected state.
It is for a list of choices the user picks from. `NavRow` is the sibling for a row that goes somewhere.

<Canvas of={Stories.ChoiceList} />

### Usage

```tsx
import { OptionRow } from "@lufia/design-system/components/OptionRow";

<ul>
  <li>
    <OptionRow
      title="Team plan"
      description="Up to ten people."
      leading={<UsersIcon />}
      selected={picked === "team"}
      trailing={picked === "team" ? <CheckIcon /> : undefined}
      onClick={() => setPicked("team")}
    />
  </li>
</ul>;
```

Strings in the snippet are plain literals. In your app they arrive through props from your copy layer.

### Compact density

`density="compact"` is for a long pick list inside a menu, sheet or modal. The row loses its border and shadow, takes tighter
block padding, a medium-weight title and the small muted description. Separate the rows with the parent's gap, or draw a
hairline there. On a coarse pointer a compact row is at least `--lufia-target-touch` tall.

<Canvas of={Stories.CompactList} />

### Keyboard

| Key               | Action                                             |
| ----------------- | -------------------------------------------------- |
| `Tab`             | Moves focus to the row (a disabled one is skipped) |
| `Enter` / `Space` | Activates the row                                  |

### Accessibility

- The row is a native `<button type="button">`; its name is the title, the description and any text in the trailing slot.
- `selected` is `aria-pressed`, so the chosen row is announced as pressed and the state is never colour alone: the border
  and fill change, and the trailing slot can carry a check. Group the rows in a list or a labelled group.
- The leading slot is decorative and hidden from assistive technology.
- The `selected` state is `aria-pressed` on the button and `aria-current` on an element given to `render`; pick the one the
  element's role fits and do not set both.
- Comfortable rows are at least 3.5rem tall, above the touch target floor. Compact rows are 2.5rem on a fine pointer and at
  least `--lufia-target-touch` on a coarse one. Focus shows the shared ring.
- In forced-colors mode the selected row takes a thicker `Highlight` border.
- The press scale is off under `prefers-reduced-motion`.

<Section id="guidelines">

### When to use

- A short list of options, each with a name and a line of detail: a plan, a template, a delivery address.

### When not to use

- A row that navigates to another page: use `NavRow`.
- A set where exactly one choice applies and the options are one word: use `RadioGroup`.
- A choice among a few short labels in a bar: use `SegmentedToggle`.

### Content guidelines

A title of one to four words, and a description that says what picking it means.
