<Section id="overview">

A key figure with its label, an optional change and hint, and a slot for a small chart: the tile of a dashboard. With `href` or `onClick` the whole tile is one link or button.

<Canvas of={Stories.WithSparkline} />

### Usage

```tsx
import { StatTile } from "@lufia/design-system/components/StatTile";
import { AnimatedNumber } from "@lufia/design-system/motion";
import { Sparkline } from "@lufia/design-system/components/Sparkline";

<StatTile
  label="Open items"
  value={<AnimatedNumber value={128} />}
  delta="12% vs last week"
  trend="up"
  trendLabel="Up"
  hint="Across all teams"
  sparkline={<Sparkline values={[3, 5, 4, 8, 6, 9, 12]} label={null} />}
  href="/items"
/>

<StatTile label="Open items" value="--" loading loadingLabel="Loading open items" />
```

Strings in the snippet are plain literals. In your app they arrive through props from whatever copy or i18n layer you use; the package has none.

### The interactive tile

An interactive tile is not a clickable `div`. It uses the stretched-link pattern, like `Card`: the `label` renders as the one link (or button) and its `::after` pseudo-element covers the tile. The figure, the change and the hint are attached to it with `aria-describedby`, so a screen reader announces "Open items, link, 128, up 12% vs last week" once. Hover lifts the tile a little and press scales it down slightly, both from motion tokens and both removed under reduced motion.

The standard trade-off of the pattern: text in the tile cannot be selected with the mouse.

### As a filter

A row of tiles can filter a list. Give each button tile `pressed` and keep the active key in your own state: the button exposes `aria-pressed`, and the pressed tile gets an accent border and background, a doubled inset border and a check mark, so the state never rests on colour. `pressed` is ignored on link tiles and on plain tiles.

```tsx
<StatTile label="Overdue" value="4" pressed={filter === "overdue"} onClick={() => setFilter("overdue")} />
```

### Counting up

The `value` is a node, so pass an `AnimatedNumber` to count to a new figure. The tile adds no motion of its own to the number.

### Computing the change

`computeStatDelta` turns two numbers into the change props, so every tile words and tones its change the same way. It is pure and has no language of its own: the direction words and the period come in through `labels`.

```tsx
import { StatTile, computeStatDelta } from "@lufia/design-system/components/StatTile";

<StatTile
  label="Open tickets"
  value="7"
  {...computeStatDelta({
    current: 7,
    previous: 10,
    goodDirection: "down",
    locale: "en",
    labels: { up: "Up", down: "Down", flat: "No change", comparison: "vs previous 30 days" },
  })}
/>;
```

The result is `{ delta, trend, trendLabel, deltaTone }`, for example `"-30% vs previous 30 days"`, `"down"`, `"Down"` and `"success"`. A screen reader hears "Down -30% vs previous 30 days". Props written after the spread win, so `deltaTone="danger"` overrides the computed tone. `previous` of `null`, `undefined` or `NaN` returns `null`; spreading `null` adds nothing.

| Option          | Default        | Effect                                                                                                      |
| --------------- | -------------- | ----------------------------------------------------------------------------------------------------------- |
| `mode`          | unset          | `"percent"` or `"absolute"` forces the format. A base of exactly `0` is always absolute.                    |
| `minBase`       | `5`            | Below this `\|previous\|` the default mode shows the absolute change, so 1 to 4 reads "+3", not "+300%".    |
| `formatValue`   | `Intl`         | Formats the size of an absolute change (no sign: the helper adds it): units, compact notation.              |
| `flatThreshold` | `0.5`          | A percentage change within plus or minus this many percent is flat. In absolute mode only equality is flat. |
| `badTone`       | `"warning"`    | Tone of a change in the wrong direction; set `"danger"` for a critical figure.                              |
| `locale`        | runtime locale | Formats the number: `pt-PT` gives "+3,5%".                                                                  |

The percentage has one decimal under 10 percent and none from 10 percent. It divides by the size of the previous value, so a rise from `-10` to `-5` is a positive change.

### Keyboard

| Key   | Action                                       |
| ----- | -------------------------------------------- |
| Tab   | Interactive tile: focuses the link or button |
| Enter | Follows the link, or presses the button      |
| Space | Presses the button                           |

A plain tile is not focusable. The focus ring is drawn around the whole tile.

### Accessibility

- The accessible name of an interactive tile is its `label`. The figure, change and hint are its description.
- `trend` draws a decorative arrow. Say the direction in words with `trendLabel` ("Up") or inside `delta`, so the direction never rests on the arrow or the colour.
- `tone="warning"` and `"danger"` tint the tile. The label and hint must say why it needs attention.
- While `loading`, the tile is `aria-busy`, the link or button is removed and each skeleton takes the line box of what it replaces (the figure, the change, the hint, the chart), so the loaded tile has exactly the same height. Pass the same `delta`, `hint` and `sparkline` while loading as you will once loaded: they decide which lines are held. Set `loadingLabel` to announce it once.
- With `pressed`, the button is a toggle: screen readers announce "Open items, toggle button, pressed". Name the filter in the `label`, not in the state.
- In `forced-colors` mode the border is `CanvasText` (`Highlight` when pressed, with the check mark) and the focus ring `Highlight`.

<Section id="guidelines">

### When to use

- A figure people scan first on a dashboard: a count, a rate, an amount.
- A shortcut to the filtered list behind the figure.

### Choosing the change

- Set `goodDirection` by meaning, not by arithmetic: more open incidents is bad (`"down"`), more orders is good (`"up"`). Use `"neutral"` when neither is better; the tile then never turns green or amber.
- Always state the period in `labels.comparison` ("vs previous 30 days"). A bare "+12%" does not say against what.
- Hide the change until there is history: pass the previous value as `null` and spread the `null` result. Never show "0%" or a made-up baseline for a new figure.
- Leave `minBase` at its default unless the figure is naturally large or tiny. A percentage on a base of 1 or 2 is noise, and a base of 0 has no percentage.
- A flat change is neutral and carries its own direction word, so it does not read as good or bad.

### When not to use

- A figure inside a sentence or a table cell: format it as text.
- Several figures in one tile: use one tile per figure.
- A tile whose destination is unrelated to the figure: use a `Card`.
