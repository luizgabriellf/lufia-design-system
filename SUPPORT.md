# Getting help

- **Questions and ideas:** open a [GitHub Discussion](https://github.com/luizgabriellf/lufia-design-system/discussions) if it is enabled, otherwise an issue using the _Question_ option in the issue chooser.
- **Bugs:** open a [bug report](https://github.com/luizgabriellf/lufia-design-system/issues/new?template=bug_report.yml). Include the package version, a minimal reproduction (a Storybook story is ideal), and the browser and assistive technology if it is an accessibility problem.
- **New components or tokens:** open a [component request](https://github.com/luizgabriellf/lufia-design-system/issues/new?template=component_request.yml) (the RFC flow in [CONTRIBUTING](CONTRIBUTING.md)).
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).
- **Documentation:** the [Storybook site](https://luizgabriellf.github.io/lufia-design-system/) is the reference.

This is a volunteer-maintained project; there is no support SLA. Please be patient and kind (see the [Code of Conduct](CODE_OF_CONDUCT.md)).
